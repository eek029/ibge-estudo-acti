# 6. COBIT e ITIL

**Edital:** frameworks amplamente utilizados como o COBIT e o ITIL.

Este é o bloco que **mais diferencia** candidatos em provas de governança de TI.

---

## 6.1 ITIL — Information Technology Infrastructure Library

### O que é
Conjunto de **melhores práticas** para **gestão de serviços de TI** (não é norma certificável ISO; é framework/prática).

### ITIL v3 / 2011 — 5 etapas do ciclo de vida (ainda cai em prova)
| Etapa | Foco |
|-------|------|
| **Service Strategy** | Estratégia, portfólio, demanda, financeiro |
| **Service Design** | Projetar serviços, catálogo, SLA, disponibilidade, capacidade, continuidade, segurança |
| **Service Transition** | Mudança, release, configuração, conhecimento (SACM/SKMS) |
| **Service Operation** | Operação do dia a dia: incidentes, problemas, eventos, requisições, acesso |
| **Continual Service Improvement (CSI)** | Melhoria contínua |

### Processos da Operation (decorar)
- Event Management  
- **Incident Management**  
- Request Fulfillment  
- **Problem Management**  
- Access Management  

### ITIL 4 — conceitos modernos (cada vez mais cobrados)
- **Service Value System (SVS)**  
- **Service Value Chain:** Plan · Improve · Engage · Design & Transition · Obtain/Build · Deliver & Support  
- **4 dimensões:** organizações e pessoas; informação e tecnologia; parceiros e fornecedores; fluxos de valor e processos  
- **Guiding principles** (exemplos): focus on value, start where you are, progress iteratively, collaborate, think holistically, keep it simple, optimize and automate  
- Práticas (practices) em vez de só “processos rígidos”

### Para a prova, priorize
1. Incidente vs problema vs mudança  
2. SLA / catálogo  
3. Ciclo de vida v3 **ou** value chain v4 (saber que ambos existem)  
4. Melhoria contínua

## 6.2 COBIT — Control Objectives for Information and Related Technology

### O que é
Framework de **governança e gestão de TI** empresarial (ISACA). Foco: alinhar TI ao negócio, gerar valor, otimizar risco e recursos.

### COBIT 5 — princípios (clássicos de concurso)
1. Atender às necessidades das partes interessadas  
2. Cobrir a organização de ponta a ponta  
3. Aplicar um framework único integrado  
4. Possibilitar uma abordagem holística  
5. Separar **governança** de **gestão**  

### COBIT 5 — 7 enablers (habilitadores)
Princípios/políticas/frameworks · Processos · Estruturas organizacionais · Cultura/ética · Informação · Serviços/infra/aplicações · Pessoas/habilidades  

### Governança vs gestão no COBIT
| Governança (EDM) | Gestão (PBRM) |
|------------------|---------------|
| **E**valuate | **P**lan |
| **D**irect | **B**uild |
| **M**onitor | **R**un |
| | **M**onitor |

### COBIT 2019 — atualização (saber existência)
- Mais flexível; **design factors**  
- Objetivos de governança e de gestão  
- Mesma essência: valor, risco, recursos, stakeholders  

### Objetivos de alto nível (ideia)
- Entregar valor  
- Otimizar risco  
- Otimizar recursos  
- Alinhamento estratégico

## 6.3 COBIT × ITIL × ISO 27001 (quando usar o quê)

| Framework | Foco principal |
|-----------|----------------|
| **COBIT** | Governança e gestão corporativa de TI; controles; alinhamento com negócio |
| **ITIL** | Gestão de **serviços** de TI (operação e valor do serviço) |
| **ISO 27001** | SGSI — segurança da informação como sistema de gestão |
| **PMBOK** | Gestão de **projetos** |

São **complementares**, não rivais. Prova adora perguntar “qual framework…”.

---

## 6.4 Pegadinhas frequentes

- ITIL **não** substitui COBIT  
- COBIT **não** detalha “como abrir um ticket” como ITIL  
- ISO 27001 **não** é framework de service desk  
- Separar governança (dirigir/avaliar) de gestão (executar) é cobrado em **COBIT**
