## Bloco I — Estruturas lógicas (prioridade máxima)

### Conectivos
| Símbolo | Nome | Tabela-verdade (ideia) |
|---------|------|------------------------|
| ¬ / ~ | negação | inverte V/F |
| ∧ | e (conjunção) | V só se ambos V |
| ∨ | ou (disjunção) | F só se ambos F |
| → | se… então (condicional) | F só em V→F |
| ↔ | se e somente se | V se iguais |

### Negação de proposições compostas
- ¬(p ∧ q) ≡ ¬p ∨ ¬q  
- ¬(p ∨ q) ≡ ¬p ∧ ¬q  
- ¬(p → q) ≡ p ∧ ¬q  
- ¬(p ↔ q) ≡ (p ∧ ¬q) ∨ (¬p ∧ q)

### Condicional e equivalentes
- p → q ≡ ¬p ∨ q  
- p → q ≡ ¬q → ¬p (contrapositiva)  
- **Não** equivalente: q → p (recíproca) nem ¬p → ¬q (inversa)

### Quantificadores
- Todo A é B → negação: Existe A que não é B  
- Algum A é B → negação: Nenhum A é B  
- Nenhum A é B → negação: Algum A é B

## Bloco II — Lógica de argumentação

- Premissas × conclusão  
- Argumento **válido**: se premissas verdadeiras, conclusão necessariamente verdadeira (forma)  
- Sofismas comuns: generalização indevida, falso dilema, apelo à autoridade  

Tipos cobrados:
- Modus ponens: p→q ; p ∴ q  
- Modus tollens: p→q ; ¬q ∴ ¬p  
- Silogismo hipotético: p→q ; q→r ∴ p→r
