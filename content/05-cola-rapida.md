## Específicos — 30 segundos cada

### PMI/PMBOK
- Projeto = temporário + único · Programa = projetos relacionados · Portfólio = alinhamento estratégico  
- Grupos: iniciação, planejamento, execução, mon. & controle, encerramento  
- Áreas no edital: escopo, prazo, custo, qualidade, riscos, comunicação, aquisições  
- Canais de comunicação: n(n−1)/2  
- Contingência = riscos conhecidos · Reserva gerencial = desconhecidos  

### Riscos
- Evitar · Mitigar · Transferir · Aceitar · Escalar (ameaças)  
- CPI = EV/AC · SPI = EV/PV (&lt;1 = ruim)  

### Segurança
- C confidenciais · I integridade · A disponibilidade · + autenticidade  
- RBAC · menor privilégio · MFA  
- Simétrica = 1 chave · Assimétrica = par · Hash = integridade  
- Incidente: preparar → detectar → conter → erradicar → recuperar → lições  
- RTO = tempo de volta · RPO = perda de dados aceitável  

### Normas / lei
- **27001** = SGSI certificável · **27002** = práticas de controles  
- NIST CSF: Identify · Protect · Detect · Respond · Recover  
- LGPD: titular · controlador · operador · encarregado · ANPD · bases legais · princípios  

### Governança / serviços
- Governança = direcionar/avaliar · Gestão = executar  
- SLA = com cliente · OLA = interno · UC = fornecedor  
- Incidente = restaurar · Problema = causa raiz · Mudança = alterar com controle  

### Frameworks
- **ITIL** = gestão de serviços  
- **COBIT** = governança e gestão de TI (EDM × PBRM)  
- **PMBOK** = projetos  
- **27001** = segurança (SGSI)  

### Gestão estratégica
- PETI/PDTI alinhados ao negócio  
- Portfólio: investir / manter / aposentar  
- Transformação digital = valor + cultura, não só ferramenta  
- Maturidade: ad hoc → gerenciado → definido → quantificado → otimizando
